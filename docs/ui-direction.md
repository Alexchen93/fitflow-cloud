# FitFlow：週期訓練紀錄冊

## 核心
把「動作資料 → 週期安排 → 當次執行 → 訓練回顧」串成一條可操作的流程。MVP 暫不加入姿勢辨識、AI 計畫或假資料。

## 視覺方向
Carbon、骨白、signal lime；以訓練單、週次尺規、索引與帳本呈現內容。保留高辨識數字、細線與硬邊，避免裝飾漸層和泛用鼓勵標語。這是原創排版，不複製第三方品牌、素材或版型。

## 資訊架構
- 今日：下一堂訓練、預估時間、動作數、目前週次與單一開始入口。
- 計畫：四期目的與每週課程；目前週期條僅表示階段，不宣稱是實測負荷曲線。
- 動作庫：搜尋、分類、肌群與可展開的動作說明。
- 訓練：固定計時與組數進度、逐組勾選、就地查看操作要點、RPE 及完成儲存。
- 紀錄：真實完成堂數、分鐘與近期訓練明細，不加入虛構成效指標。

## 行動體驗
底部導覽保留安全區；320px 起不產生整頁橫向溢出。手機仍保留課程時間、肌群與休息秒數。操作具焦點狀態與 reduced-motion 支援。儲存重試沿用同一個 runId。
